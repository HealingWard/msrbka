# Прицел — поиск товаров

Веб-сайт по дизайну «Прицел — поиск товаров» из Claude Design. Вы описываете товар обычными словами,
«Прицел» разбирает запрос (цвет, размер, бюджет, бренд), уточняет недостающее, ищет в выбранных магазинах
(Яндекс Маркет, Lamoda, Stockmann) и ранжирует выдачу по соответствию.

## Что умеет

- **Поиск** — разбор свободного запроса («белые кеды Veja, 38 размер, до 15 000»), выбор магазинов, брендов и категорий.
- **Уточнение** — спрашивает только то, чего нет в запросе; магазины и размер обязательны.
- **Результаты** — процент соответствия и объяснение «почему подходит», фильтры (магазин, бренд, размер, цвет, цена),
  сортировка, вид «сетка» или «таблица». Адрес выдачи содержит все параметры, поэтому её можно обновить или отправить ссылкой.
- **Товар** — разбор соответствия по пунктам и интерактивный график истории цены за 30, 90 или 180 дней.
- **Мои поиски** — сохранённые запросы, повторный запуск и удаление.
- **Избранное** — подборки, цена на момент добавления и её изменение, мини-график.
- **Выгрузка в Google Таблицу** — предпросмотр листа; кнопка копирует строки в буфер (при вставке в Google Таблицы
  ссылки становятся гиперссылками); таблицу можно также скачать в CSV.
- Поиски, избранное, подборки и настройки хранятся в `localStorage` браузера и синхронизируются между вкладками.
- Вёрстка адаптирована под телефоны: фильтры открываются в полноэкранной панели, таблицы прокручиваются по горизонтали.

> Каталог и история цен — **демонстрационные данные** из дизайна (`src/data/catalog.js`). Кнопки «Открыть в магазине»
> ведут на настоящий поиск этого товара на сайте магазина. Чтобы подключить живые цены, нужен сервер-посредник
> к API или каталогам магазинов: из браузера это сделать нельзя из-за ограничений CORS.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # юнит-тесты разбора запроса, ранжирования и выгрузки
npm run build    # статическая сборка в dist/
npm run preview  # просмотр собранной версии
```

Сборка статическая, а маршрутизация идёт через hash (`#/results?...`), поэтому `dist/` можно выложить на любой
статический хостинг (GitHub Pages, Netlify, Vercel, S3) без настройки сервера.

### GitHub Pages

В репозитории есть workflow `.github/workflows/deploy.yml`: он собирает сайт при пуше в `main`.
Один раз включите **Settings → Pages → Source: GitHub Actions**.

## Структура

```
src/
  data/catalog.js        магазины, бренды, цвета, товары
  lib/search.js          разбор запроса, оценка соответствия, фильтры, сериализация поиска в URL
  lib/priceHistory.js    история цены и статистика
  lib/export.js          строки выгрузки, CSV, копирование для Google Таблиц
  lib/format.js          числа, рубли, склонения, даты
  lib/storage.js         состояние, которое сохраняется в localStorage/sessionStorage
  lib/router.js          hash-маршрутизация
  state.jsx              общее состояние приложения
  screens/               Главная, Уточнение, Результаты, Товар, Мои поиски, Избранное
  components/            карточка и таблица товаров, график цены, окно выгрузки, мелкие элементы
```
