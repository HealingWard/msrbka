# Сервер поиска «Прицела»

Ищет товары в **Lamoda**, **Stockmann** и **Яндекс Маркете** и отдаёт сайту настоящие карточки:
ссылку на товар в магазине, цену, старую цену, фото, а где магазин их показывает — размеры, цвет, рейтинг.
Каждую увиденную цену сервер записывает, поэтому история цены копится с первой проверки.

## Как устроен разбор

Готовых API для поиска у этих магазинов нет, поэтому сервер загружает страницу выдачи, как браузер,
и извлекает товары тремя независимыми способами (`src/extract.js`):

1. разметка schema.org (JSON-LD: `Product`, `ItemList`, `Offer`);
2. данные, встроенные в страницу (`__NEXT_DATA__`, `window.__…STATE__ = {…}`, `<script type="application/json">`);
3. карточки в HTML: ссылки, похожие на адрес товара этого магазина (`productPath` в `src/stores.js`), и цена рядом.

Результаты склеиваются по адресу товара. Ссылки на чужие сайты отбрасываются.
Если магазин отвечает капчей или 403/429, сайт показывает «магазин не пустил» и ссылку на поиск в самом магазине.

**Ограничения, о которых надо знать:**
- Магазины меняют вёрстку и защищаются от роботов. Яндекс Маркет почти всегда показывает капчу запросам с серверов.
  Lamoda и Stockmann обычно доступнее, особенно с российского IP.
- Разбор проверен на тестовых страницах, повторяющих типичную разметку, но не на живых сайтах: из среды разработки
  они были недоступны. После запуска выполните `npm run probe` (см. ниже) — он покажет, что удаётся извлечь.
- Соблюдайте правила сайтов магазинов. Сервер ходит к каждому магазину не чаще раза в 1,5 с и кэширует выдачу на 20 минут.

## Запуск

Нужен Node.js 20+.

```bash
cd server
npm install
npm start                 # http://localhost:8787/api/health
npm test                  # тесты разбора и API
npm run probe -- all "бежевый тренч"   # что сервер видит в каждом магазине
npm run probe -- url https://www.lamoda.ru/p/…/   # разбор конкретной карточки
```

`probe` сохраняет сырой HTML в `server/probe/`. Если какой-то магазин отдаёт страницу, но товаров 0,
откройте этот файл, найдите ссылку на карточку товара и поправьте `productPath` для магазина в `src/stores.js`.

Без доступа к магазинам можно проверить всё остальное на сгенерированных страницах:
`node scripts/mock-server.js` — тот же API, но «магазины» подменены (Маркет в нём всегда отвечает капчей).

### Настройки (переменные окружения)

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `PORT` | `8787` | порт |
| `DATA_DIR` | `./data` | где хранить `prices.json` с историей цен |
| `ALLOWED_ORIGINS` | `*` | с каких сайтов разрешены запросы, например `https://healingward.github.io` |
| `CACHE_MINUTES` | `20` | сколько минут держать выдачу в кэше |
| `STORE_GAP_MS` | `1500` | минимальная пауза между запросами к одному магазину |
| `RATE_PER_MINUTE` | `60` | запросов в минуту с одного IP |

## Размещение

Сайт на GitHub Pages работает по HTTPS, поэтому и серверу нужен HTTPS-адрес.
Лучше всего брать VPS в России (Timeweb Cloud, Selectel, REG.RU и т. п., от ~200 ₽/мес):
с российских адресов магазины реже включают защиту от роботов.

```bash
# на сервере с Docker
git clone https://github.com/HealingWard/msrbka.git && cd msrbka/server
docker build -t pricel-server .
docker run -d --name pricel --restart=always -p 127.0.0.1:8787:8787 \
  -v pricel-data:/data -e ALLOWED_ORIGINS=https://healingward.github.io pricel-server
```

HTTPS проще всего получить через [Caddy](https://caddyserver.com/) — он сам выпустит сертификат.
Направьте домен (например, `api.example.ru`) на IP сервера и положите в `/etc/caddy/Caddyfile`:

```
api.example.ru {
    reverse_proxy 127.0.0.1:8787
}
```

## Подключение к сайту

В корне репозитория в `public/config.json` укажите адрес сервера и отправьте изменение в `main`:

```json
{ "apiUrl": "https://api.example.ru" }
```

После сборки сайт начнёт искать настоящие товары. Пустой `apiUrl` возвращает демо-каталог.

## API

| Запрос | Ответ |
|---|---|
| `GET /api/search?store=lamoda&q=тренч` | `{ status: "ok" \| "blocked" \| "error", items: [...], error, searchUrl }`; `store` — `lamoda`, `stockmann` или `market` |
| `GET /api/product?url=<ссылка на товар>` | товар с размерами и фото + `history: [{t, price}]` |
| `GET /api/history?id=lamoda:MP002…&id=…` | `{ [id]: [{t, price}] }` |
| `GET /api/stores`, `GET /api/health` | список магазинов, проверка работы |
